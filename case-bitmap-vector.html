A local-first bitmap-to-SVG converter for logos, icons and stickers

一个完全在浏览器本地运行的小工具，把 PNG / JPG / WebP 快速转换成 SVG。 我围绕 上传、参数调节、对比预览、下载与复制代码 搭建完整体验， 让设计素材处理从复杂软件操作变成一个轻量、可分享的前端工具。

01 · Problem

素材转 SVG，不应该总要打开重型软件

设计师、运营和前端都可能遇到同一个小问题：手上只有位图，但交付或排版需要 SVG。

目标不是替代专业矢量软件，而是服务 logo、图标、贴纸这类边缘清晰、颜色较少的素材。

// Pain
流程过重
常规方案需要打开设计软件或在线转换站点，对简单素材来说操作成本偏高。
// Risk
隐私顾虑
Logo 和品牌素材上传到第三方服务，会让用户担心文件外传。
// Goal
轻量可控
上传后立即预览，通过少量滑杆调节结果，再下载 SVG 或复制代码。

04 · Next

后续可以继续扩展的方向

MVP 已经能完成核心转换链路，下一步可以围绕质量、性能和批量效率继续迭代。

// Quality
转换质量
增加更多阈值策略、颜色合并策略和路径简化选项，提升复杂 logo 的可控性。
// Performance
Web Worker
把矢量化模块迁移到 Worker，避免大图处理占用主线程，提升交互流畅度。
// Output
更多导出
增加 PNG 预览导出、批量转换和转换前后滑动对比，覆盖更多真实工作流。
